# 페이서 (Pacer) — MVP 범위 확정 v1

> 상위 문서: 기능 명세(P0/P1 태깅) 외 설계 문서 세트 v1
> 목적: 1차 출시(MVP) 범위를 확정하고, 이후 로드맵을 분리

---

## 1. MVP 원칙

- **핵심 가설을 검증하는 최소 범위**: "공고·직무를 넣으면 쓸 만한 맞춤 면접 + 납득되는 평가가 나온다"
- P0(필수)만 1차 출시, P1 이후는 로드맵으로 분리
- 무거운 항목(IAP, LLM 품질)은 리스크로 별도 관리

---

## 2. MVP 포함 — Phase A (클로즈드 베타 · 결제 제외)

> **출시 전략: 2단계(베타 → 정식) 확정.** 아래 §2는 Phase A(품질 검증 베타), 수익화는 §2B(Phase B).

### 인증 / 온보딩
- 소셜 로그인: **카카오 + 애플**(필수) — 구글 로그인은 P1(확정, 슬림화)
- 온보딩: 닉네임 + 필수 동의(약관·개인정보·LLM 전송)

### 면접 준비
- 공고 입력: **텍스트 복붙**
- **직무 카테고리 선택**(대분류 → 세부)
- 지원자 정보: 경력·자기소개(권장), 이력서(선택·스킵)

### 면접 설정
- 면접 유형: **일반 / 압박** (2종)
- 난이도, 기본 질문 수
- 점수 표시 on/off 토글

### 면접 진행
- 채팅 면접 + 꼬리질문(종료 판단)
- "모르겠습니다" 스킵
- 일시정지 / 이어하기

### 결과
- 최종 리포트: **종합 점수 + 합격/불합격 + 판정 근거 + 항목별 점수 + 모범답안**
- **직무별 평가 가중치**(대분류 프리셋)

### 기록
- 히스토리 목록 + **대화 전문 재열람**

> Phase A 한도: 결제가 없으므로 무료 한도는 넉넉히(또는 무제한 베타). 카운트 로직은 넣되 페이월은 미노출.

---

## 2B. Phase B (정식 출시 — 수익화 부착)

Phase A로 면접·평가 품질이 검증된 뒤 부착.

- 무료 한도(하루 기본 질문 20개) + 자정 리셋 **활성화**
- **한도 소진 페이월 + 구독 결제(IAP)** — 애플/구글 상품 등록·서버 영수증 검증·복원
- (선택) 구글 로그인 추가

---

## 3. MVP 제외 (P1 이후 로드맵)

| 항목 | 사유 | 배치 |
|------|------|------|
| URL 공고 자동 파싱 | 복붙으로 대체 가능 | P1 |
| **실시간 피드백(+토글)** | 최종 리포트로 충분, 구현·품질 부담 | P1 |
| 인성/직무/임원 유형 | 일반·압박으로 시작 | P1 |
| 면접관 페르소나 | 부가 요소 | P1 |
| 언어 선택(영어 면접) | 한국어 우선 | P1 |
| 성장 추이(차트) | 데이터 쌓인 후 가치 | P1 |
| 리포트 공유/내보내기 | 바이럴, 후순위 | P1 |
| 부적절 질문 대응 코칭 | 차단은 P0(가드레일), 코칭 콘텐츠는 후순위 | P1 |
| 세부 직무 미세 가중치 | 대분류 프리셋으로 시작 | P1 |
| 구글 로그인 | 카카오·애플로 커버 | P1 |

> 실시간 피드백은 P0 설정 토글과 P1 생성 로직이 어긋나 있었음 → **MVP에서 실시간 피드백 자체를 제외**하고 토글도 P1로 통일(정합성 정리).

---

## 4. MVP 마일스톤 (9단계 구현과 연결)

**Phase A (베타)**
1. 백엔드 코어: 스키마 → 인증(카카오/애플) → 세션·메시지 API
2. LLM 파이프라인: 질문 생성 → 꼬리질문 → 최종 평가(직무 가중치) + 스키마 검증
3. Flutter 앱: 온보딩 → 준비/설정 → 진행(SSE) → 리포트 → 히스토리
4. 클로즈드 베타 배포 → **면접·평가 품질 검증**

**Phase B (정식)**
5. 수익화 백엔드: 한도 카운트(Redis/자정) → IAP 검증
6. 페이월/구독 연동 → 통합 테스트
7. QA · 스토어 심사 · 정식 배포

---

## 5. MVP 리스크 (선관리)

- **LLM 평가 품질/일관성** = 핵심 가설. 프롬프트·가중치 검증에 시간 투자 (6단계 문서 기반)
- **IAP 구현 공수**: 애플/구글 상품 등록 + 서버 영수증 검증 + 복원 → 은근히 큼
- **LLM 비용**: 무료 20질문 × 사용자 규모의 유닛 이코노믹스 사전 점검
- **개인정보**: 이력서·자소서 LLM 전송 동의·파기 (출시 전 필수)

---

## 6. MVP 성공 기준 (최소 KPI)

| 지표 | 정의 | 왜 |
|------|------|----|
| 활성화 | 가입 → 첫 면접 완료율 | 온보딩·입력 마찰 점검 |
| 완주율 | 시작한 면접의 완료 비율 | 면접 UX·길이 적정성 |
| 리포트 만족 | 리포트 👍 비율 | 평가 품질(핵심 가설) |
| 재방문 | D7 리텐션 | 반복 연습 가치 |
| 전환 | 무료 → 구독 전환율 | 수익화 성립 |

---

## 7. 출시 전략 — 2단계 (확정)

- **Phase A (클로즈드 베타)**: 결제 제외, 면접+평가 **품질 검증**에 집중 (§2)
- **Phase B (정식 출시)**: 페이월 + 구독 결제 부착 (§2B)

품질이 약하면 결제를 붙여도 전환이 안 나므로, 품질 검증 → 수익화 순서로 확정.
IAP 공수를 Phase B로 미뤄 Phase A 출시 속도를 확보.
