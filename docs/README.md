## 결정 기록 (ADR)

**왜 그렇게 정했는가**는 [`decisions/`](./decisions/)에 따로 모은다.
위 스펙 문서가 "무엇을 만드는가"(항상 현재 상태)라면, ADR은 "왜 그렇게 정했나"(그 시점 스냅샷)다.

> 6개월 뒤에 "왜 이렇게 됐지?"를 다시 물을 것 같으면 ADR, 한 번 읽고 닫을 거면 이슈.

작성 규칙과 목록은 [`decisions/README.md`](./decisions/README.md) 참조.
